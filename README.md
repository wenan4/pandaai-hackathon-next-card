## 本地运行

安装 Node.js 24（版本见 `.node-version`），在仓库根目录执行：

```sh
npm ci
npm run dev
```

打开终端显示的网址。生产构建与本地预览：

```sh
npm test
npm run build
npm run preview
```

Git检出目录还可运行 `npm run build:pages` 执行完整发布检查；源码ZIP的运行方法不依赖Git元数据。

前端直接使用仓库内的派生数据和美术，不需要 `.env`、Python、数据库、外部模型接口或任何密钥。手机局域网访问、Cloudflare 配置和故障处理见 [运行说明](docs/RUNNING.md)。

## 怎样试玩

1. 选择“开始旅程 · 生成本局观察”；“只玩游戏”保留游戏进度，但不生成研究画像。
2. 城门战先看意图，选择手牌并打出；右上角“怎么玩”集中解释规则。回合结束时未保留的手牌弃置，之后仍可再抽到。
3. 营地可买牌、升级、补生命、买档案和安排投资。第一次不投，中途和最后营地仍能投入或追加；档案买一次、逐站免费更新。
4. 点击“我的交易风格”回看资金取舍、资料使用和应对变化；通关、失败或返程后会直接进入报告。
5. 在报告“研究与下一步”进入“金币够不够用？”或“这次涨跌，真的说明什么？”，按页面步骤判断、核查并查看反馈。这些练习不扣游戏金币。

评委可从“菜单 → 评委面板”查看模拟路径，或从实际关键选择前分叉、改变安排并观察后果。模拟有来源标记，可恢复真实旅程；详见 [评委复现步骤](docs/SUBMISSION.md#评委复现步骤)。
