# 第三方组件、AI 工具与赛前成果

## v0.4.1 MVP 新增工作

2026-10-31 至 2026-11-01，本分支在已有 v0.3 工程上重构冒险主线。使用 Codex 协调三个 GPT-6.1 Terra（max）子代理，分别开发战斗/经营引擎、数据/研究画像和界面交互；主代理负责 PRD 修订、整合、审查与验证。运行时画像与推荐使用本地确定性函数，不调用大模型。

美术使用 OpenAI 内置 GPT Image 工具生成原创场景与角色。首版夜景按用户意见改为阳光童话小城；角色按用户反馈修订。具体文件、提示和用途见 [美术来源](adventure-art.md)。未复制商业游戏角色或卡面。

新主线借鉴卡牌构筑、过载与成长的通用机制，卡牌名称、数值、效果组合和角色视觉为本项目设计。Panda Data 数据继续采用本地离线获取、发布派生数据、按阶段加载的方式。真实试玩和正式赛事视频不因代码完成而被视为已完成；见 [验证记录](MVP-VERIFICATION.md)。

本地功能演示由 Playwright 通过页面控件录制，使用 FFmpeg 转为 H.264 MP4；没有配音或背景音乐。录制工具仅位于忽略的输出目录，不加入运行时依赖。该视频是自动化功能示范，来源与处理记录见 [演示说明](DEMO-WALKTHROUGH.md)。
