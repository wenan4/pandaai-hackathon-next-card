## 赛前成果与本次完成工作

团队负责人于2026-11-01明确确认：**没有复用赛前成果**。本仓库v0.3为比赛期间形成的前一轮迭代，v0.4.1在其数据与工程基础上重构。第三方软件、数据服务与AI工具按下文单独披露；不把它们声称为团队原创。

比赛期间的核心工作：

1. Panda Data取数验证、缓存与历史案例筛选，前复权/同日程口径及分阶段静态数据导出。
2. 早期v0.3翻牌研究原型、规则计算、测试、评委分叉与结构化输出。
3. v0.4.1卡牌冒险：14种牌、四场战斗、岔路、成长/过载/保留、补给与金币经营。
4. 三处营地的参与/追加/回收规则、实际开盘结算与逐站档案；存档兼容、失败重试和数据可见边界。
5. 带事件依据的本局画像、资金安排与历史对照练习、帮助/已见记录、推荐与预期对照。
6. 手机分页、横滑、集中教学与两轮用户试玩反馈整改；阳光童话场景和角色资产。
7. 自动化测试、手机尺寸验证、密钥扫描、GitHub CI和Cloudflare Pages部署。证据见[验证记录](MVP-VERIFICATION.md)，不把自动化验证当作真人心理测评。

## 数据、开源项目与制作工具

- **Panda Data / panda_data 1.0.5**：离线获取行情、指数、交易日历等。本地数据脚本依赖Python、NumPy、pandas、PyArrow与python-dotenv，具体依赖见 `scripts/requirements.txt`。这些工具不进入浏览器运行时，评审不需要账号；不分发原始缓存或凭据。
- **数据披露**：发布的是归一化曲线、相对报价和派生统计；案例为教学筛选，部分窗口相关或后验选取。数据授权与使用边界沿用[数据说明](adventure-data.md)，不把派生处理等同于额外取得授权。
- **QuantSkills / quantskills/skill-quant-research**：研究方法参考（项目标注GPL-3.0-only），借鉴固定判断、基准比较和样本边界；没有复制其代码，也没有接入其执行引擎。[方法来源](https://github.com/quantskills/skill-quant-research)。
- **Playwright**：开发期浏览器自动化与验证，不作为真人试玩证据；不进入产品运行依赖。
- **FFmpeg**：制作既有本地H.264演示视频；视频处理和对应版本见[演示说明](DEMO-WALKTHROUGH.md)。视频及工具本体未纳入网站。
- **GitHub Actions / Cloudflare Pages**：代码检查与静态网站部署。

## AI工具与资产

- **Claude Code（Anthropic）**：辅助前一阶段代码、数据脚本、测试和文档；相关提交保留 `Co-Authored-By: Claude` 或相应模型标记。
- **OpenAI Codex 与 GPT-6.1 Terra（max）子代理**：辅助PRD修订、游戏重构、研究/画像、界面、代码审查、测试、用户反馈整改与部署整合。团队负责需求判断和最终确认。
- **OpenAI GPT Image / ImageGen**：开发期生成和编辑场景、旅行者、守灯者、钟鸟及苔壳角色。具体文件与提示见[美术来源](adventure-art.md)。按用户意见改为明亮场景并去掉钟鸟胸口下方挂球。

卡牌构筑、过载、成长等属于机制参考；项目自行实现规则和数值，未复制商业游戏角色或卡面。当前网站的画像、推荐和模拟均使用仓库中的确定性函数，**运行时不调用大模型或图片生成接口**。
