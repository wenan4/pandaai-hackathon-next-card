# v0.4 冒险数据、执行口径和边界

数据来自项目现有 **Panda Data `panda_data` 1.0.5** 本地缓存：前三案对应已发布的 `public/data/cases_reveal.json` 中 R1、R2、R3，第四案沿用 R3 标的的另一历史窗口。这里没有发布原始 OHLCV、账号或密钥；公开展示许可尚无明确答复，前端只展示以各自 T0 收盘归一的派生比例和统计。数据截止日为 2026-10-30。游戏金币、商品价格、敌人和奖励是虚构规则，不是真实交易或投资建议。

`lantern-c` 和 `lantern-d` 是同一标的、时间重叠的相关情境；不能因为编号不同把已见数据算作独立新证据。D 的 T0 历史已包含 C 的部分未来行情，因此新客户端先固定本局案例，再单独获取该案 T0 及以前的历史。D 所跨窗口中 2025-04-16 有一条已缓存复权事件；所有报价仍是以截止日为锚的前复权派生比例，并非严格点时执行回测。

战斗胜利后才推进该段历史。未完成下一段就失败或返程时，从**已经推进的最后时间点之后**取下一个允许的实际开盘，不取完整路径的终点，不将自动回收当成主动退出。行情缺失时订单保持待结算，不用上一收盘、零值或手工数值替代。

## 接口、计算和限制

- `get_stock_daily_pre` 提供资产前复权日线开盘与收盘；`get_index_daily` 提供沪深300同日开盘与收盘；`get_trade_cal` 提供交易日与下一交易日。资产和基准各以自己的 T0 收盘 = 1,000,000 归一并取整，所有阶段报价都是整数相对比例，不是原始价格。
- 前复权使用数据截止日作为锚；归一比例可用于本演示的历史比较，但不是严格点时可成交价格，不将其自动表述为含分红总回报。样本包含停牌和成交量检查，交易限制仅在关键执行开盘做涨跌停排除；这不保证真实成交。
- 游戏支持虚拟小数份额，现金最小单位为 0.01 金币；份额以 10^12 定点保存、按真实相对开盘价结算，现金在实际到账时四舍五入。演示不模拟手续费、印花税、滑点、冲击、买卖盘或完整涨跌停成交限制，也不模拟交易单位、税务和再投资。
- 同期比较要求资产与基准共享交易日、固定同一参与及回收日程；基准指数只是对照，并不声称可以无成本买卖该指数。持有期间最大回撤按实际仍持有时的价格路径计算，主动回收造成的份额变少不会误记为价格跌幅。不同历史段比较仅是固定日程的条件算例，不等于玩家在另一行情下会作同样的决策。
- D1 将已经发生的收入、采购和未支付尝试写为显式固定外部需求；若某次采购付不起，停止后续运算。玩家改变参与金额后的战斗结局与后续行为没有被重演，也不被冒充为事实。没有已成交的真实路径时提供明确标记的**人工机制算例**，不称为历史行情。

## 数据文件与可见信息

为兼容已上线旧版，原 `manifest.json` 和 `integrity.json` 的字节保持不变，仍描述原三案；新客户端读取不含历史价格序列的 `manifest.v2.json`，固定案例后再读取 `initial/<case>.json`，只包含该案 T0 及此前的历史。每个未来阶段在 `stages/<case>/<stage>.json` 单独请求。收盘文件仅含刚揭晓的这一段历史与同期基准；执行文件只有该次实际下一开盘的相对报价。D2 的 `research/<case>.json` 只有在用户先锁定可核查判断与固定日程后请求。浏览器通过静态文件切分避免界面提前误用未来信息，**不声称阻止技术用户自行查看**；已看过答案或相关案例的重试需保留暴露记录，不能计作独立新证据。

旧版 SHA-256 仍在 `integrity.json`，新版全部文件的 SHA-256 列在 `integrity.v2.json`。本地重建方式（可信 pickle 只能从本项目原有缓存读取）：

```powershell
python scripts/build_adventure_data.py --cache-dir <原仓库的scripts/cache目录>
```

生成程序只读这些本地缓存：`get_stock_daily_pre_02e833a86d7db295.pkl`、`get_index_daily_fc1b7a02aa4373cb.pkl`、`get_trade_cal_dcbc1ea6d1a405ad.pkl`；它不读取或输出账号、凭据、token，也不向前端导出原始日线。生成时核对旧版 T0 历史及冻结文件，若缓存产生不同字节则停止而不是覆盖旧数据。

为便于独立复核，一个**真实历史派生**算例：lantern-a 的 entry、T1 收盘、T1-exec 分别为 994131、903365、901017（T0=1,000,000）。投入 40 金币约得 40.236146 份；T1 参考价值约 36.35 金币；收回一半按下一开盘得到约 18.13 金币。参考价不是成交价，也不是现实收益承诺。

另一个仅供复核的**历史派生**算例：lantern-d 的 entry、T1 收盘、T1-exec 分别为 997436、869028、866698；投入 40 金币时，T1 参考价值约 34.85 金币，比参与金额低约 12.88%。这使预设 10%–20% 条件在合适的现金、生命、未见与自主选择情境下有可能自然匹配；不保证每一局匹配，更不推断或预先填充用户感受。案例是后验选出的，不能据此推算未来走势。

QuantSkills 的 [`quantskills/skill-quant-research`](https://github.com/quantskills/skill-quant-research)（GPL-3.0-only）仅作研究方法参考：D2 借鉴先锁定可证伪判断、对照简单基准、披露样本与未来边界。项目未复制其代码，也未集成其执行引擎或获得官方认证。
