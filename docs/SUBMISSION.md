## 评委复现步骤

### 手机正常体验

1. 打开正式H5，选择“开始旅程 · 生成本局观察”。右上角“怎么玩”可查看集中教学；开始时无需输入个人资料。
2. 城门战：看中间意图，选择手牌、点“打出”、结束回合；奖励需确认加入。手牌可横滑，未保留的牌在回合结束后进入弃牌堆。
3. 第一营地先看金币安排，可以选0。进入档案、买牌或补给分页。未安排前消费会提示余额，仍可自主决定。
4. 中途营地可首次投入或追加；档案可在结算前买，之后免费更新。最后营地可同时回收旧份额并追加，实际成交后显示金额。
5. 点击“我的交易风格”；通关、失败或返程也会直接进入报告。查看三类本局线索及选择依据，再从“研究与下一步”进入练习。
6. 资金安排台先判断一笔采购是否付得起，再试另一种安排；历史对照台固定金额/日程后比较案例与同期市场，并可看另一片段。练习不改动游戏金币，理由可跳过。

### 追问或改变关键选择

1. 正常旅程有经营选择后，打开“菜单 → 评委面板”。
2. 选一个“参与/回收/历史档案”的检查点，点击“从这里分叉”。回到当时合法状态，改投入金额或回收比例，再走后续操作。
3. 比较现金、持有份额、可买项目、后续线索和推荐。新结果由同一正式规则产生；原记录不会被改写成分叉后的行为。
4. 点击“恢复真实旅程”。也可先使用“路径甲 / 路径乙”两条标注为模拟的预设，再修改关键选择作对照。

### 数据、推荐与隐私核对

- “菜单 → 数据说明”：查看Panda Data接口、案例、基准和本局已经揭晓的报价，不提前展示未发生阶段。
- 报告“选择依据”与“研究与下一步”：核对原事件、任务证据、实际帮助和推荐理由。缺少证据时保持未知，不用胜负或收益给金融能力打分。
- “菜单 → 设置”：查看本地记录与观察状态，可撤销观察或确认清除；只玩模式不保存研究画像。

## 来源、示例和未完成事项

- 行情是Panda Data真实历史的归一化派生数据；金币、敌人和奖励是游戏规则。人工算例与真实历史窗口分别标示，见[数据说明](adventure-data.md)。
- 评委预设、分叉、校准对照均是模拟。推荐在本地按规则计算，未接入PandaAI生产账户或运行时大模型。
- 目前仅提供本局观察，不提供经过验证的固定人格类型、现实风险承受等级或投资建议。新版人物卡分享导出、跨设备账户同步等未实现，见[状态表](PROJECT.md#功能状态)。
- 已有本地MP4是较早版本的自动化功能演示，未包含最近改动；本次提交以正式H5和当前源码为准。如附视频，应说明其对应版本或重新录制。
