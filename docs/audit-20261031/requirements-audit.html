3. “评委改一项选择”具体怎么落地

赛题并未要求做开放聊天机器人，也未要求每次改选都换标签。评委可口头追问，作品用依据页回答；改选则应现场运行同一个规则引擎。现有 §9 已有“只改最终判断后重算”的设计，不能说完全遗漏；但只切换甲乙等预设路径不够证明任意改选。

  1. 进入评委面板，能选择当前真实体验记录或明确标注的模拟路径作为基线。
  2. 选任意一轮，改首翻／已翻牌、最终判断、追问答案或交易行动；支持撤销和恢复基线。
  3. 保留原始事件不可变，另建“反事实模拟”分支。修改已揭晓历史不会冒充玩家新增独立表现。
  4. 重新检查翻牌上限、事件阶段、追问触发及帮助暴露。若改判断触发了新的追问，要求填写或明确跳过，不能遗留不可能发生的旧答案。
  5. 并列显示原值、新值、命中规则、画像／进度／推荐／下一步变化；不变时解释为什么不变。
  6. 所有结果来自同一套 evaluate / recommend；预设路径、现场操作和比较页不得各自硬编码答案。

4. 三轮确实偏少：建议 6 轮核心＋最多 2 轮复核

题数多本身不能保证可靠。现有问题是 O1、O2、O3 各只测一个情境，而 O4 可能没有冲突机会；推荐跳过基础任务又只需要前两项各一次 observed。使用“本局倾向”能限制宣传，却不能增加证据。赛题没有规定最低题数，也没有要求完成 MBTI 式人格量表；本建议依据本产品的证据需求，不把六轮视为心理测量有效性的证明。

阶段新情境安排作用
第 1–3 轮：初步发现保留对照、长历史、未来证据边界三种玩法展示初步卡片及已有依据；明确哪些仍只观察到一次，先给可用下一步。
第 4 轮：复核对照能力另一标的／时段，改变命题真假方向；例如这次确实跑赢预先指定基准不能靠记住“第一题选不支持”通过。
第 5 轮：复核长窗口能力另一完整历史情境；例如收益为正但回撤不满足题设，或反向配置检验是否同时理解条件与窗口，不能只看上涨就答支持。
第 6 轮：复核证据边界同时区分可由已给样本核对的历史描述与无法保证的未来断言；数据本身完整避免把“未来问题永远点证据不足”误认为完整研究能力。此轮题型与 O3 定义需同步修订。
最多 2 轮针对性复核优先处理跨情境表现矛盾、关键证据未看、理解不确定；使用未看过的新案例仍不确定就保留不确定，不能一直加题直到用户“答对”。用户可跳过。

第 3 轮先反馈，第 6 轮再完善结果，用户可从初步结果进入推荐任务。仍须记录其证据较少；不能把未玩的后半段当完成。原来每轮约 50–60 秒，直接翻倍可能接近 5–6 分钟纯游戏，加说明与任务后更长；先压缩重复操作，用试玩确定总时长。

必须同步改规则：从按“第几轮”判能力改为按“能力项＋情境 ID”聚合；增加独立情境数、支持／冲突记录及帮助记录；将“已观察到一次”与“跨情境重复出现”分开展示。可暂以同类能力在两个不同新情境中独立完成、且无未解释冲突，作为跳过对应基础练习的产品门槛；这只是待试玩的规则，不是统计置信度。完成带提示的基础任务后仍能进入 B，不能让复核门槛卡住用户。

首翻风格改为展示各类选择次数和覆盖情境；没有足够记录时保持混合／未确定，不能把旧版“三轮里两次”的阈值原样套到六轮。R6、复核题和新事件需要新的规则版本；五条演示路径、结构化示例、推荐条件、验收与视频脚本必须一起更新。给过同题答案后的重做不算独立，新题迁移表现也不能宣传成稳定人格。

5. Panda Data 保留必做，但减少无关工程

材料把合理运用 Panda Data 列为核心任务，并设置 15 分应用价值。它没有要求调用越多越好，也允许少量数据形成完整体验。因此本次建议以实际使用、用途清楚为完成标准，不为了接入而建设完整回测平台。

  • 最小数据范围：少量标的及预先指定基准，取需要的交易日期、价格、成交量和历史窗口；具体接口及权限待实际核验。
  • 实质进入玩法：真实数据生成趋势、同期比较和历史指标；翻开不同牌会改变玩家看到的证据，系统判断也由这些数据及冻结命题得出。仅把 Panda Data 放在来源页不算完成。
  • 离线可用：取数后生成获准展示的派生缓存，现场可完整运行；本地保存接口、参数、生成时间、处理口径与来源证据，网页不含密钥。
  • 命题跟随数据：冻结合法筛选与表述规则，不能为了指定结论伪造行情。模拟反例只在评委面板单独标注，不混入真实案例。
  • 后续任务控制范围：先把任务 A 和一个已核验的 B 主题做完整。不同用户仍通过 A/B、需要补的步骤、协助档位、先猜后验获得差异。若只做一个 B 主题，删除“物种改变研究主题”的已完成宣称，明确多主题尚未完成。
  • QuantSkills：核验一个确实适用的资源即可，注明条目、链接、用途与授权；不要求把整个技能库接入，也不能把拟采用资源写成已实现。

少量数据仍需准确口径。若保留任务 B 的信号组／基准组比较，就仍需它所依赖的时间边界、样本计数与排除规则；不能仅因缩范围而删除必要计算检查。可通过减少主题和股票池规模控制工作量。

7. 下一版 PRD 的优先修改清单

  1. P0 · 现场可核查：将评委任意改选、依赖校验、前后比较、解释不变结果写成明确交互，按第 3 节用例验收。
  2. P0 · 增加有效证据：采用“3 轮初步反馈、6 轮核心、最多 2 轮复核”的候选方案；同时重写跨情境聚合、基础任务跳过条件及风格统计，试玩后冻结。
  3. P0 · 实际数据：验证少量 Panda Data 数据能够取到、允许展示，产出真实案例、来源记录及可操作任务。对接能力未完成前如实标注。
  4. P0 · 可运行工程：建立代码与启动说明，跑通手机上的游戏→画像→依据→推荐→操作→更新；随后再谈实现覆盖率。
  5. P0 · 提交完整性：补项目说明、运行依赖、第三方／AI／赛前成果说明、团队联系人、提交渠道、截止时间与评审访问检查。
