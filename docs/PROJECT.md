## 产品与玩法

玩家从混合基础牌组开始，在四场战斗和两次岔路中选择卡牌、补给和升级。战斗中的能量、过载、成长、保留以及敌人意图均可查阅；奖励先选择、确认后加入。守灯者的新战斗生命为75，旧战斗存档保留原状态。

金币同时用于旅程消费和历史价格中的虚拟投资。首营地、中途营地、最后营地分别提供资金安排机会；后两站可以回收旧份额并追加新投入。追加只能用当前可用金币预留，与回收按同一个下一开盘报价执行。历史档案只付费一次，到新营地免费补入已经揭晓的行情。

手机主流程使用分页、横滑和按需弹窗；“怎么玩”集中提供五个主题。游戏完整时长与易懂程度仍以真实用户试玩为准，不把自动化操作时长当成人类体验时长。

## 怎样帮助用户认识自己

| 内容 | 行为依据 | 结果与用途 |
|---|---|---|
| 资金取舍 | 每次安排前的现金、参与/追加金额、消费与预留 | 说明本局怎样分配金币，区分提交、预留、实际成交 |
| 信息使用 | 档案购买、实际打开及其所在营地 | 说明是否查阅资料；买了不等于打开，打开不等于理解 |
| 应对变化 | 持有份额时的参考价值、成本、回收及追加选择 | 解释具体情境下的安排，没有选择机会时保留未知 |
| 知识与研究过程 | D1可用金币判断；D2同期比较、跨片段比较；初答、看到的资料、终答 | 给出任务观察、需要核查的步骤和下一练习 |
| 兴趣与学习需求 | 本人选择的练习目标、帮助方式及实际使用帮助 | 调整推荐内容与提示程度，允许本人修改 |
| 游戏打法 | 连招、战斗与奖励记录 | 单列战报，不自动映射为金融人格 |

报告标题为“我的交易风格”，实际内容是带依据的**本局画像**，并非经过验证的固定人格测评。系统区分自主完成、看到提示后完成、复习、模拟及资料不够等情况；理由可跳过，不代替用户编造原因。

## 研究与推荐

- **资金安排台 / 金币够不够用？**：先用买牌例子解释题意，再以本局的一笔采购判断可用现金是否足够，修改最初安排进行固定日程试算。后续追加按原金额保留，资金不足时暂停。它不改写游戏金币或重演改变选择后的战斗。
- **历史对照台 / 这次涨跌，真的说明什么？**：先固定同金额、同时间的安排，再看历史案例和同期市场；可进一步比较另一片段并描述结果。它是条件比较练习，不冒充用户在另一市场中实际作过的选择。
- 推荐结合本局资料使用、资金阻碍、任务证据和明确目标；有可执行入口与理由。真实PandaAI账户回写未接入。

## 数据与隐私

无需姓名、手机号或金融账户。游戏进度和选择保存在本机浏览器；观察可撤销，验证到期后清理并保留游戏进度。网页请求同站静态资源和派生数据，不包含第三方行为统计或模型接口上传。

真实用户的本地记录、手动备份和导出可能包含行为与自述，供本人保存；不是公共人物卡。截图、录屏及分享时使用新演示局或清晰标注的模拟，不公开未授权记录。详见 [提交要求对照](SUBMISSION.md)。
